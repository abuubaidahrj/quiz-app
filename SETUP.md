# Math Master v6.0 — XP, Streaks & Achievements

New features: XP, daily streak, levels, badges, and a student progress panel. Targeted Practice still does not send email. All sessions still submit to Google Sheets.

XP rules:
- Every question: +10 XP
- Fast first-try answer under 5 seconds: +5 XP
- Perfect assessment: +50 XP
- At least 90% first-try accuracy: +25 XP
- Targeted Practice completed: +30 XP

Storage note: v6.0 stores XP, streaks, and badges in the current browser using localStorage keyed by Student ID. They do not yet synchronize across devices.
